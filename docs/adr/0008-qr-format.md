# ADR-0008: Формат QR-кодов

- Статус: принято
- Дата: 2026-04-17

## Контекст

В системе сканируется много разных сущностей: паспорта, ячейки,
оборудование, коробки. Нужно, чтобы при сканировании клиент мог сразу
понять, что это, и направить в нужный хендлер.

## Решение

Универсальный формат значения QR-кода:

```
{kind}:{id}
```

Примеры:

```
passport:clx123abc
cell:clx456def
equipment:clx789ghi
box:clxabc000
```

- `kind` — из фиксированного множества `passport | cell | equipment | box`.
- `id` — `cuid` из БД.

На клиенте:

```ts
function parseQr(raw: string): { kind: QrKind; id: string } { ... }
```

При несоответствии — ошибка «Неизвестный QR-код», без side-effects.

## Альтернативы

- URL-формат `https://app.example.com/p/clx123abc` — плюс в переходимости
  по ссылке, минус в зависимости от домена и длине.
- Чистый `id` без `kind` — неоднозначно, опасно.

## Последствия

+ Тривиальный парсинг.
+ Не зависит от домена.
− Не открывается браузером напрямую (требуется приложение). На MVP — ОК.
