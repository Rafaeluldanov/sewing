Раскройщик: раскрой + выпуск паспортов в одном кабинете

Структура по решению владельца: три вкладки верхнего уровня — Раскрой · Выпуск · Стеллаж. Это режимы работы за столом, а не блоки на одной простыне: кроим в первой, печатаем паспорта по закрытым раскладам во второй, размещаем крой в третьей.

РаскройПодкрой и очередь задач как сейчас; в окне раскладов появляется «Расклад готов» — частичное завершение по заказу
Выпускочередь заказов с закрытыми раскладами: видно частичное завершение, паспорта печатаются по раскладу
Стеллажразмещение в ячейку — без изменений; ячейка липкая до конца смены
Счётчик на «Выпуске»каждый «Расклад готов» сразу увеличивает бейдж вкладки — видно, что накопилось к печати

Сквозной пример на всех экранах: заказ 01-00040 · Футболка Classic · белый, план S 60 · M 160 · L 80 · XL 30. Расклад 1 закрыт (M×2, L×1; рулоны 20/18/22/16 слоёв → 8 паспортов), расклад 2 закрыт (S×2, XL×1; 14/14 → 4 паспорта), расклад 3 настилается. Выпущено 2 паспорта из 12.

Как сейчас: фактические экраны кабинета /cutter · срисовано с кода, не концепт

Базлайн, поверх которого строится всё ниже. Источники: cutter/page.tsx, cutter-board.tsx, recut-panel.tsx, [id]/cutting-form.tsx, seamstress-shift-start.tsx, cutter/layout.tsx. Тексты кнопок, подсказок, пустых состояний и порядок блоков — дословно из кода, включая шероховатости (узкое поле поиска в «Подкрое» — это реальный .cutter-input шириной 5.5rem).

Частичное завершение раскроя — в текущем окне раскладов /cutter/[id] · открывается из вкладки «Раскрой»

То же окно, что на экране F, — добавляется одна кнопка «Расклад готов» в каждый расклад. Закрытый расклад зеленеет, становится read-only и сразу даёт выпускать по нему паспорта, пока следующий настилается. «Раскрой завершён» внизу остаётся — закрывает всё, что ещё открыто.

Несколько расцветок в заказе Ф3 colorways · настил многоцветный, каждый рулон = один цвет

Механика уже есть в проде: при 2+ расцветках у рулона появляется колонка «Цвет» (селект по расцветкам заказа), «на настиле» остаётся общим на настил — маркер по цвету не делится. Паспорт красится в цвет своего рулона; рулон без расцветки падает на базовый цвет заказа. Частичное завершение ничего в этом не меняет — цвет просто едет через закрытый расклад в выпуск.

Вкладка «Раскрой» /cutter · первая из трёх вкладок кабинета

В «Раскрое» только кроим: Подкрой и очередь задач — как в проде. Тап по задаче открывает окно раскладов с «Расклад готов» (раздел «Окно раскладов» выше). Каждый закрытый расклад сразу увеличивает счётчик на вкладке «Выпуск».

Вкладка «Выпуск» очередь закрытых раскладов → печать паспортов по раскладу

Заказ появляется здесь по первому закрытому раскладу — в карточке видно, что раскрой частичный и по каким раскладам уже можно печатать. Тап по заказу — форма выпуска: закрытые расклады выбираются, открытые ждут пунктиром. Выпущенные паспорта и план-факт — по ссылке внутри заказа.

Вкладка «Стеллаж» третья вкладка · без изменений

Полный поток за смену: первый вход во вкладку — скан ячейки камерой → подтверждение (код + что уже лежит внутри) → сессия «сканируй паспорта один за другим». Ячейка липкая: живёт до конца смены, повторный вход во вкладку продолжает сессию без скана. Ошибка одного паспорта сессию не рвёт. Backend тот же, что у помощника: /cells/by-code → /passports/by-code → /passports/:id/place.

Помощник раскройщика: закрыт ровно расклад 1 /work · тот же read-model, другая оболочка

Момент времени: раскройщик нажал «Расклад готов» на раскладе 1 (M×2, L×1 · рулоны 20/18/22/16 слоёв), расклады 2 и 3 ещё настилаются, паспортов не выпущено ни одного. Помощник в этот момент видит заказ впервые — раньше он ждал бы «Раскрой завершён» по всему заказу. Его экраны не перестраиваются: данные те же (ready-for-release + release-state), меняется только условие попадания в очередь и набор выбираемых раскладов.
