Ассистент в админке — макет

Окно диалога с ИИ внутри /admin/*: справка по системе + чтение реальных данных. Доступ — всем, у кого открыта админка (ADMIN, SHOP_MANAGER и кастомные роли), поэтому выдача режется правами на бэкенде.

Границы этого макета.
  • Ассистент только читает: никаких изменений в БД, кнопок «сделай» нет.
  • Каждый вызов инструмента виден пользователю строкой — не «чёрный ящик».
  • Ответ по данным всегда заканчивается источниками — ссылками на реальные сущности, чтобы число можно было проверить глазами.
  • Права режет бэкенд, а не промпт: закрытые данные ассистент не видит вообще.
  • Настройка — вторая карточка на существующей вкладке «Интеграции» (экран 3), отдельного раздела фича не заводит.
  • Не показано: мобильный вид, история диалогов.

«Расчёт готов» — заказ просчитан: есть спецификация, потребность цеха и плановая себестоимость. На этом статусе ещё можно править состав и количество — окно правки закрывается запуском в производство.

Дальше доступно:

  • запустить в производство (создаст паспорта);
  • отправить потребность в закупку;
  • вернуть в черновик, пока не выпущен крой.
