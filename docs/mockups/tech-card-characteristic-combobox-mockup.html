Техкарта: «Подтип» убираем, «Характеристика» становится пополняемым списком

Сегодня в строке материала техкарты два поля-соседа: «Подтип» (жёсткий выпадающий список из MATERIAL_SUBTYPES — Молния, Кнопка, Кашкорсе, Дублерин, Синтепон…) и «Характеристика полотна» (свободный текст, fabricType). Подтип нельзя дополнить из интерфейса — новое значение требует правки кода.

Предложение по вашей задаче: поле «Подтип» удалить, все его значения перенести в список поля «Характеристика», а само поле сделать комбобоксом — можно выбрать из списка, можно набрать своё; набранное сохраняется в список и в следующий раз предлагается наравне с готовыми.

Одно поле вместо двух«Роль материала» → «Характеристика». Больше ничего выбирать не нужно.
Список привязан к ролиУ «Фурнитуры» свой список (Молния, Кнопка…), у «Основного полотна» — свой (кулирка, футер…).
Список растёт самНабрал «кашкорсе 2×2» → «+ Добавить» → значение в справочнике для всех техкарт.
Старые техкарты живутЗаполненный subtypeKey при открытии переезжает в «Характеристику» его лейблом.

2. Как станет

«Подтип» из формы исчезает. Остаётся одно поле «Характеристика» — комбобокс. Кликните по нему в макете: он живой, список открывается, значения выбираются, новое можно добавить.

3. Комбобокс: четыре состояния

Все четыре — рабочие, можно потыкать. Пятый блок — как список выглядит после того, как в него добавили своё.

3.1 Пусто → клик открывает весь список

Клик по пустому полю показывает весь список роли — не нужно угадывать первую букву.

3.2 Набор текста → список фильтруется

Совпадение подсвечено. Регистр и лишние пробелы не важны.

3.3 Совпадений нет → «+ Добавить»

Жёлтая строка внизу — единственный способ пополнить список, и он же обычный ввод: нажали Enter или кликнули — значение и записано в строку, и добавлено в справочник роли.

3.4 Уже добавленные — с меткой и удалением

Значения, добавленные пользователями, помечены своё и их можно убрать из списка крестиком (в техкартах, где значение уже проставлено, текст остаётся — удаляется только подсказка).
Клавиатура. ↑/↓ — по списку, Enter — выбрать подсвеченное (или добавить новое, если совпадений нет), Esc — закрыть, Tab — принять текст как есть. Значение, набранное и не подтверждённое через «+ Добавить», всё равно сохраняется в строку техкарты — вопрос ниже: молча пополнять список или только по кнопке.

Старые техкарты

Если в строке лежит subtypeKey, при открытии он показывается в «Характеристике» своим лейблом — ничего не теряется и не требует ручной правки.

5. Что нужно решить до кода

Три развилки — от ответов зависит объём работы. Ответьте прямо в чате, макет поправлю.

① Под-поля бывшего подтипа

Подтип не только назывался — он включал поля: «Молния» → Тип, Длина; «Пуговица» → Тип, Материал, Размер, Кол-во проколов; полотно на «кг» → требовало Плотность и Ширину рулона.

  1. Оставить связь скрытой — выбрали из списка знакомое значение, под-поля появились как раньше; набрали своё — под-полей нет. Минимальная правка, ничего не ломается.
  2. Убрать совсем — под-поля показываются всегда, независимо от значения (или их просто нет). Проще в голове, но теряется правило «для кг обязательны плотность и ширина рулона».

② Когда значение попадает в список

  1. Только по «+ Добавить» — осознанное действие, список чище.
  2. Автоматически при сохранении техкарты — ноль лишних кликов, но список быстро зарастёт опечатками.

③ Кто может пополнять и чистить

  1. Любой, кто редактирует техкарту (быстро, но без контроля).
  2. Пополнять — все, удалять/переименовывать — только через страницу справочника в админке.

Нужна ли отдельная страница справочника в админке (как у остальных справочников, с архивом) — или хватит правки прямо из комбобокса?
