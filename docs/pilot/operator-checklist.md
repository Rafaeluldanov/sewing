## Operator Checklist (что и в каком порядке)

> Бумажная версия — печатать и держать на рабочем месте. Один пункт = одно
> физическое или цифровое действие.

---

### Раскрой

- [ ] Открыть `Заказы` → нужный заказ.
- [ ] Убедиться, что заказ в статусе `IN_PRODUCTION` (бейдж).
- [ ] «Выпустить паспорт» → размер → количество → рулон → «Создать».
- [ ] Открыть карточку паспорта → «Печать» → A6.
- [ ] Наклеить распечатку на пачку.
- [ ] «Разместить в ячейке» → выбрать ячейку → «Сохранить».
- [ ] Положить пачку в ту же ячейку.

Контроль: после действия в карточке заказа в столбце «Раскроено» по
размеру цифра увеличилась.

---

### Швея

- [ ] Открыть `Рабочее место`.
- [ ] Выбрать оборудование и операцию → «Начать смену».
- [ ] Когда нужен крой: «Получить крой» → сканировать QR паспорта в
      ячейке.
- [ ] На каждой следующей операции: «Сканировать паспорт» → QR.
- [ ] По окончанию работы: «Завершить смену».

Контроль:
- после «Получить крой» статус паспорта стал `IN_PROGRESS`;
- после скана текущая операция в `/passports/:id` сменилась на вашу.

---

### ОТК

- [ ] Открыть `ОТК`.
- [ ] Найти паспорт (по номеру / рулону / заказу / изделию).
- [ ] Открыть карточку паспорта.
- [ ] Если есть брак: вид брака → количество → комментарий →
      «Зафиксировать брак».

Контроль:
- цифра «Брак» в карточке паспорта увеличилась;
- «Годных» = «Раскроено» − «Брак»;
- в `/orders/:id` итог `Брак` по заказу тоже вырос.

---

### ВТО

- [ ] Открыть `Рабочее место`.
- [ ] Смена с операцией `WTO` → «Начать смену».
- [ ] Сканировать паспорт через «Сканировать паспорт».
- [ ] Физически передать пачку упаковщику.

---

### Упаковка

- [ ] Открыть `Рабочее место` → смена с операцией `PACKING` → «Начать
      смену» (без неё упаковка заблокирована).
- [ ] Открыть `Упаковка` → «Создать коробку».
- [ ] Открыть карточку коробки → сканировать QR паспортов один за другим.
- [ ] Когда коробка заполнена — «Закрыть коробку».

Контроль:
- статус каждого добавленного паспорта стал `PACKED`;
- `totalQty / maxQty` коробки совпадает с фактом;
- `qtyFinishedTotal` в заказе вырос на сумму годных по этим паспортам.

---

### Начальник цеха

Каждый день, минимум:

- [ ] Утром — `Цех` (`/shopfloor`): убедиться, что прошлая смена закрыта,
      нет «зависших» паспортов в `PACKING`.
- [ ] Днём — `Заказы`: создать новые заказы, запустить в производство.
- [ ] Вечером — `Зарплата` (`/earnings`): подтвердить, что суммы за день
      адекватны (нет аномалий).
- [ ] Раз в день — `Админ → Обзор` (`/admin/overview`): активные смены,
      открытые коробки, паспорта без ячейки.

При любом обращении сотрудника:
- спрашиваем `requestId` из красной плашки ошибки;
- открываем `feedback.md` и фиксируем как `critical` / `medium` / `low`.
